## 2. 아직 남은 일 — 사장님 계정이 필요한 작업

### ① Apps Script 재배포 (가장 급함)

**하지 않으면 신청 폼의 "관심 검사" 값이 시트에 안 들어가고, 후기 기능이 전혀 작동하지 않는다.**

1. 구글 시트 열기 → **확장 프로그램 → Apps Script**
2. 레포의 `apps-script/Code.gs` **전체를 복사해 편집기에 덮어쓰기**
3. **배포 → 배포 관리 → 편집(연필 아이콘) → 버전: "새 버전" → 배포**
4. 확인: 사이트에서 테스트 신청 1건 → 시트 `신청내역` 마지막 행에 `관심검사` 값이 있는지

시트 헤더와 `후기` 탭은 코드가 자동으로 만든다. 기존 데이터 행은 건드리지 않는다.

### ② 후기 승인 방법

1. 방문자가 후기를 남기면 시트 `후기` 탭에 `승인(Y/N)` = **N** 으로 저장되고 알림 메일이 온다
2. 내용을 확인하고 게시할 것만 **승인 열을 `Y` 로 변경**
3. 잠시 후 `https://neobanalab.com/reviews.html` 에 자동으로 표시된다

연락처는 사이트로 절대 나가지 않는다(본인 확인용).

### ③ 검색 등록 — 국내 유입의 핵심

**네이버 서치어드바이저** (https://searchadvisor.naver.com)
1. 사이트 등록: `https://neobanalab.com`
2. 소유확인: HTML 태그 방식 선택 → **메타태그를 담당자에게 전달하면 전 페이지에 삽입**
3. 요청 → 사이트맵 제출: `https://neobanalab.com/sitemap.xml`
4. 요청 → 웹페이지 수집: 주요 페이지 수동 요청

**구글 서치 콘솔** (https://search.google.com/search-console)
1. 속성 추가 → URL 접두어 `https://neobanalab.com`
2. 소유확인: HTML 태그 방식 → **메타태그 전달**
3. Sitemaps → `sitemap.xml` 제출

> 두 곳 모두 소유확인 메타태그만 알려주시면 담당자가 즉시 삽입·배포한다.

### ④ 구글 비즈니스 프로필 (지역 검색)

https://business.google.com → 비즈니스 등록
- 업체명 **너바나**, 카테고리: 교육 컨설턴트 / 심리 상담
- 주소: 동탄 상담실 주소 (공개 여부 선택 가능)
- 전화: 010-9542-2406, 웹사이트: `https://neobanalab.com`
- 영업시간: 평일 10:00–18:00

**동탄 지역 검색 노출에는 이것이 가장 효과가 크다.** 우편 또는 전화 인증이 필요하다.

### ⑤ 도메인 자동 갱신 확인

Vercel → Domains → `neobanalab.com` → 자동 갱신 켜짐 확인.
**만료되면 사이트가 통째로 멈추고 도메인을 남이 선점할 수 있다.**

### ⑥ (선택) `neobanalab.co.kr` 확보

Vercel 은 `.kr` 을 판매하지 않는다. 가비아·후이즈에서 별도 구매(연 2만원대) 후 `.com` 으로 리다이렉트.
국내 신뢰도와 상표 방어 목적.

## 4. 하지 말아야 할 것

- 레포 루트 `CNAME` 파일 삭제 → 도메인 연결이 끊긴다
- Vercel DNS 의 A/AAAA 레코드 변경 → 사이트가 안 열린다
- `neobanalab.com` 을 Vercel 프로젝트에 연결 → 사이트가 안 열린다
- 없는 후기를 만들어 넣기 → 구글 스팸 정책 위반, 검색 제외 대상
- `data/` 폴더를 커밋 → 사업자등록증 등 민감정보가 공개된다 (현재 gitignore 처리됨)

## 5. 문제가 생겼을 때

| 증상 | 확인 순서 |
|---|---|
| 사이트가 안 열림 | ① `dig neobanalab.com` 이 `185.199.108~111.153` 인지 ② GitHub 레포 Settings → Pages 상태 ③ `CNAME` 파일 존재 |
| 신청이 시트에 안 들어옴 | Apps Script 배포 버전이 최신인지 (위 ①) |
| 후기가 안 보임 | 시트 `후기` 탭의 `승인` 열이 `Y` 인지 |
| 스타일이 옛날 그대로 | 브라우저 강력 새로고침 (⌘/Ctrl + Shift + R) |
| 검색에 안 나옴 | 서치 콘솔·서치어드바이저 등록 여부 (위 ③). 신규 도메인은 색인까지 수 주 걸린다 |
