# 지문 적성검사 랜딩페이지 — 설계 문서

작성일: 2026-05-13

## 1. 개요

친구분의 비즈니스(아동 지문적성검사)를 위한 **리드 수집 랜딩페이지**. 부모(학부모)가 페이지를 보고 자녀 정보를 남기면, 친구분이 그 정보로 연락해 비대면/방문 상담 및 검사를 진행한다.

목표는 두 가지다:
- 고객(부모)이 정보 입력 마찰을 느끼지 않고 끝까지 폼을 제출하는 것
- 친구분이 새 고객을 놓치지 않고 빠르게 연락할 수 있는 것

## 2. 사용자 · 데이터 · 워크플로우

### 주 사용자
- **고객(부모)**: 페이지를 보고 정보 입력. 공개 링크/QR로 누구나 접근.
- **친구분(검사자)**: 입력된 정보를 한 곳에서 조회 + 새 고객 알림 받음. 별도 인증 없음 — 데이터는 친구분의 구글 시트로 직접 흐른다.

### 수집 데이터 5개 필드
| 필드 | 형식 | 예시 |
|------|------|------|
| 학부모 이름 | 문자열 | 홍길동 |
| 연락처 | 숫자 (휴대전화) | 010-0000-0000 |
| 거주 지역 | 문자열 (선택형 권장) | 서울 / 경기 / ... |
| 자녀 수 | 숫자 | 1명 |
| 자녀 나이 | 문자열 (만 나이, 여러 명 가능) | 7세, 10세 |

### 워크플로우
1. 고객이 카카오톡/문자/QR로 받은 링크 클릭
2. 랜딩페이지 도착 → 카피·매니페스토 읽음 → 신청폼 작성 → 동의 체크 → "무료 상담 신청" 클릭
3. 데이터가 Google Apps Script 엔드포인트로 POST
4. 시트에 한 행 추가 + 친구분 이메일로 자동 알림 발송
5. "신청 완료" 화면/메시지 노출
6. 친구분이 이메일 또는 시트를 보고 24시간 안에 고객에게 연락

## 3. 기술 아키텍처

```
[고객 폰/PC]
   │
   ▼
[정적 랜딩페이지 (HTML/CSS/JS)]   ← Netlify/Vercel/GitHub Pages
   │  fetch POST (form data as JSON)
   ▼
[Google Apps Script 웹앱 엔드포인트]
   ├─► [Google Sheets] (영구 저장 = 친구분의 어드민 화면)
   └─► [Gmail MailApp] → 친구분 이메일로 "새 고객!" 알림
```

### 핵심 결정 이유
- **별도 서버 없음**: Apps Script가 백엔드를 대신함. 비용·운영 부담 0.
- **구글 시트가 어드민**: 친구분이 별도 페이지를 학습할 필요 없음. 폰·PC 모두에서 시트 앱으로 바로 조회.
- **이메일 알림 우선 / 알림톡 보류**: 알림톡은 비즈니스 채널 개설 + 카카오 템플릿 승인(1~3일) + 발송 대행사 가입이 필요해 초기 출시에는 무거움. 이메일은 Apps Script 한 줄로 구현되고, 나중에 알림톡 추가는 같은 엔드포인트에서 분기 처리.

## 5. 페이지 구성 (섹션 순서)

상단 nav 바, 후기 섹션 없음 — 페이지가 곧장 HERO부터 시작.

### 5.1 HERO
- **이벤트 라벨**: `● 2026 SPECIAL EVENT` (작은 오렌지 점 + 대문자 트래킹 라벨)
- **헤드라인**: "지문 적성검사 / 이벤트" (84px 거대 타이포, 줄바꿈)
- **서브카피**: "아이의 손끝에서 시작되는 9가지 다중지능 분석. 전문가 1:1 상담, 지금 무료로 받아보세요."
- **CTA**: 검정 알약 "무료 상담 신청 →"
- **보조정보**: "신청 5분 · 비대면 가능" (시계 아이콘과 함께)
- **우측 일러스트**: 오렌지 그라데이션 원 안에 모노라인 지문 SVG. 외부에 ① 흰 원 위 화살표(샛위성 CTA) ② 알약 "● FREE" 태그.
- **배경 데코**: 가는 오렌지 호선, "EVENT" 큰 워터마크

### 5.2 MANIFESTO (검정 배경 박스)
중심 메시지를 가장 강조하는 섹션. 검정 캔버스 + 가는 오렌지 궤도선.

- **라벨**: `● 우리의 약속`
- **메인 인용**:
  > 우리 아이의 가능성은 성적보다
  > 타고난 기질과 강점에서 시작됩니다.
- 가는 오렌지 가로선 (32px)
- **부연 인용**:
  > 지문검사는 아이를 바꾸기 위한 검사가 아니라,
  > 아이를 더 깊이 이해하기 위한 작은 시작입니다.

### 5.3 검사가 알려주는 4가지 관점 (2x2 그리드)
각 카드: 흰 원 안 모노라인 아이콘 → 오렌지 라벨 → 큰 타이틀 → 설명

| # | 라벨 | 메인 헤드라인 | 서브/설명 |
|---|------|------|------|
| 1 | 인격적 성향 | 100가지 유형 중 / 주성향과 보조성향 파악 | 지문에서 읽어내는 아이만의 고유한 성격 지도를 함께 살펴봅니다. |
| 2 | 학습 성향 | 어떻게 공부할 때 / 가장 잘 흡수하는지 | 시각형 · 청각형 · 체험형 중 우리 아이에게 자연스러운 학습 방식을 찾습니다. |
| 3 | 행동 · 사회성 | 대인관계 (메인) / 친구 · 가족과 관계 맺는 방식 (서브) | (설명 없음) |
| 4 | 흥미 영역 | 지치지 않고 / 몰입하는 분야 | 아이가 자연스럽게 끌리는 활동을 알면, 진로와 진학을 좀 더 일찍 준비할 수 있어요. |

### 5.4 진행 절차 (3단계, 가로 그리드)
각 단계: 흰 원 안 아이콘 → 번호 라벨 → 단계 이름 → 설명

| 번호 | 단계 | 한 줄 설명 |
|------|------|------|
| 01 신청 | 5분 정보 입력 | 이름 · 전화 · 자녀 정보만 남겨주시면 됩니다. |
| 02 상담 | 24시간 안에 연락 | 검사 방법과 일정을 친절하게 안내드립니다. |
| 03 분석 | 맞춤 리포트 제공 | 아이만의 9가지 지능 지도를 함께 살펴봐요. |

### 5.5 FORM (신청 폼)
- **라벨**: `● 지금 시작하기`
- **헤드라인**: "우리 아이만의 재능과 / 가능성을 발견해보세요."
- **폼 카드** (라이프티드 크림 배경, 40px 둥근 모서리, 부드러운 그림자):
  - 학부모 이름 (텍스트, 알약 모양)
  - 연락처 (전화 형식, 알약 모양, 숫자만 허용)
  - 거주 지역 (텍스트 입력, 자유 기재)
  - 자녀 수 (숫자) + 자녀 나이 (텍스트) — 가로 2열
  - 개인정보 동의 체크박스 + "(약관 보기)" 링크
  - 검정 CTA "무료 상담 신청하기 →"

### 5.6 FOOTER
- 사이트명 + 카피라이트만 (간단하게)
- 검정 배경 `#141413`

## 6. 데이터 흐름 · 백엔드 동작

### 폼 제출
1. 클라이언트는 JSON으로 POST: `{ name, phone, region, kidsCount, kidsAge, submittedAt }`
2. Google Apps Script `doPost` 핸들러가 받는다.
3. 검증: 이름·전화·동의 체크 필수. 전화 형식 간단 검증(숫자 9~11자리).
4. 시트의 다음 빈 행에 `appendRow` — 컬럼 순서: 제출시각 / 이름 / 전화 / 지역 / 자녀수 / 자녀나이 / 처리상태(빈값, 친구분이 수동 업데이트)
5. `MailApp.sendEmail(친구분 이메일, "[새 신청] {이름}님", 본문에 5개 필드 포함)`
6. 성공 시 JSON `{ ok: true }` 반환
7. 클라이언트가 응답 받으면 폼 카드 자리에 "신청 완료" 메시지 표시 + 폼 초기화

### 어드민 (친구분 측)
- 신규 알림: 이메일로 즉시 수신
- 일괄 조회: 본인 구글 시트 (Google Sheets 앱으로 폰에서도 조회 가능)
- 별도 어드민 페이지 없음, 인증 없음

## 7. 에러 처리

| 상황 | 처리 |
|------|------|
| 클라이언트 측 필수 필드 비어있음 | 폼 제출 막고 해당 필드에 빨간 보더 + 안내 메시지 |
| 전화번호 형식 불일치 | 알림: "전화번호를 정확히 입력해 주세요" |
| 동의 미체크 | 알림: "개인정보 수집 및 이용에 동의해 주세요" |
| Apps Script 측 검증 실패 | 400 응답, 클라이언트가 일반 에러 메시지 표시 |
| Apps Script 호출 실패 (네트워크 오류) | 클라이언트가 "잠시 후 다시 시도해 주세요" 안내, 데이터는 그대로 유지 |
| 시트 쓰기 성공, 메일 실패 | 시트는 유효하므로 클라이언트 성공 처리, 서버 로그에만 기록 |

## 8. 테스트

작은 정적 사이트이지만 다음은 수동/스크립트로 확인:

- 모바일(아이폰 사파리·안드로이드 크롬)에서 헤로·매니페스토·카드·폼이 깨지지 않는지
- PC 화면 1280·1920px에서 좌우 분할 비율, 워터마크 위치 확인
- 필수 필드 미입력 시 제출이 막히는지
- 한 번 제출 후 시트에 행이 추가되었고 이메일이 도착했는지
- Apps Script 응답이 늦거나 실패할 때 사용자에게 안내가 나가는지

## 9. 범위 외 (이번 출시에서 제외)

- 알림톡 — MVP 안정화 후 추가
- 고객 본인 인증 (이름·전화 중복 제출 방지) — 운영 데이터 보고 결정
- 어드민 검색·메모·진행 상태 관리 — 친구분이 시트로 충분히 운영 가능
- 후기 섹션, 상단 nav 메뉴 — 명시적으로 제외
